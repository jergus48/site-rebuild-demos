# Bespoke website concepts (pilot, 5 clients)

Each client has one hand-built design made for its trade. Each folder drops straight into the preview site (preview.swiftrix.eu):

    <slug>/index.html        -> preview.swiftrix.eu/<slug>   (same link as in the emails)
    <slug>/logo.png, p*.jpg  images the page uses (absolute paths /<slug>/...)

These are single static HTML files with no build step. Copy the 5 folders into the static/public folder of the `site-rebuild-demos` project. They replace the current page for these 5 clients.

All copy and prices come from the client's own website. The forms are demos and send nothing.

Performance: every page carries a small script (between `<!--swx-perf-->` markers, source `sales/perf_shim.html`). On weaker devices it turns off backdrop blur, renders canvases at 1x and runs animations at 30fps. On every device, off-screen sections skip rendering and canvas animations pause when scrolled away. `?lite=1` forces lite mode for testing. Re-apply with `python sales/apply_perf_shim.py` after adding pages.
